# About Glyph Draft

**Glyph Draft** is a glyph-drawing tool for vector art, stylistic consistency, and
SVG generation — a focused companion to a font editor, not a replacement for one.

Draw a path first, then shape its stroke outline; export FontForge-importable SVG
when you're ready.

- **Web** and **desktop** (Tauri) builds from one codebase.
- Non-destructive strokes, a two-layer Pathfinder, and per-glyph undo/redo.
